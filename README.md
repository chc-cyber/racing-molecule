# Racing Molecule · 分子赛车

**简体中文 · [English](README.en.md)**

设计一个分子，让它在金表面跑完 20 nm。

Racing Molecule 是受纳米车实验启发的开源游戏：玩家在工坊中设计赛车分子，观察它如何在热扰动、晶格起伏和外场驱动下移动、转向与变形。比赛轨迹由经典分子动力学实时计算，分子结构会通过力场中的相互作用影响比赛表现。

**[在线游玩](https://chc-cyber.github.io/racing-molecule/) · [下载发行包](https://github.com/chc-cyber/racing-molecule/releases) · [构建与发布](RELEASING.md)**

项目以可玩性为目标，同时保留可检查的 MD 底层。当前版本采用有效驱动场、冻结金表面和经过游戏适配的界面势；比赛成绩不用于预测实验纳米车速度。

## 开始游玩

1. 进入工坊，用 Ketcher 二维绘制、JSmol 三维编辑，或导入 MOL、单记录 SDF、工坊工程文件。
2. 选择标准赛事或自定义条件，将分子送入赛道。程序会检查结构，并进行分子与表面的联合几何松弛。
3. 准备完成后开始比赛。可暂停、继续，在球棍模型与空间填充模型之间切换，并选择 1× / 2× 播放。
4. 分子质心沿赛道方向净前进 20 nm 后显示成绩；平均速度以 m/s 表示，原始轨迹可下载保存。

**网页玩家无需预装 Ketcher、JSmol、LAMMPS 或 Python。** 编辑器、计算模块和势表随网页加载，MD 在玩家设备的浏览器中运行，无需计算服务器。初次加载较大，耗时取决于网络与设备；暂不承诺离线运行。

当前支持 H、B、C、N、O、F、Si、P、S、Cl、Br、I。比赛分子最多 256 个原子（含氢），跨度不超过 45 Å；具体化学环境仍须通过价态、力场参数和几何松弛检查。

## 默认赛事

| 项目 | 当前默认值 |
| --- | --- |
| 赛道 | 20 nm × 20 nm |
| 热浴温度 | 150 K |
| 驱动强度 | 0.6，游戏内部的有效强度参数 |
| 金表面 | Au(111) 代理势 v2 |
| 晶格起伏系数 | 1.5 |
| MD 时间步 | 1 fs |
| Langevin 阻尼时间 | 350 fs |
| 轨迹输出间隔 | 50 fs |

标准赛事固定规则；自定义赛事允许在准备前调整开放的参数。

计时从准备完成后的比赛初态开始。完成条件是质心相对于该初态沿赛道方向的**净位移**达到 20 nm，横向绕行不计入完成距离；成绩使用模拟时间计算，与浏览器帧率或播放倍速无关。速度换算为：

```math
\bar v\,[\mathrm{m/s}]=1000\,\frac{\Delta x\,[\mathrm{nm}]}{\Delta t\,[\mathrm{ps}]}.
```

1× 播放下，100 ps 轨迹对应约 50 秒动画；2× 对应约 25 秒。计算与播放分开运行，轨迹不足时等待缓冲，倍速不会改变时间步或比赛成绩。

## 计算模型

### 计算与动画怎样连接

LAMMPS 负责时间积分与热浴，RDKit 负责分子处理和 UFF 求力，项目自己的求力模块负责表面、驱动和边界。每个 MD 步将各部分受力汇总后交给 LAMMPS，Three.js 根据输出坐标播放轨迹。

| 部分 | 实现与职责 |
| --- | --- |
| 分子内部 | RDKit UFF：键伸缩、键角、扭转、反转和非键范德华作用 |
| C/H 与 Au | 基于 SAIP 的冻结 Au(111) 周期表面，默认使用代理势 v2 加速 |
| 其他支持元素与 Au | UFF 参数混合的各向同性 12–6 范德华近似 |
| 驱动 | 静态非均匀电场，作用于固定部分电荷和有效极化响应 |
| 边界 | 保守的软壁势，限制赛车离开比赛区域 |
| 时间推进 | LAMMPS velocity-Verlet 积分与 Langevin 热浴 |
| 画面 | Three.js 显示实际 MD 坐标；金原子图案是表面的视觉表示 |

网页版本将 LAMMPS、RDKit 和项目求力代码编译为 WebAssembly，在 Web Worker 中运行。本地版本由 Python 调用 LAMMPS/RDKit，并使用编译求力核加速。两端使用同一套模型约定，代码入口见 [网页引擎](wasm/src/engine.cpp) 与 [本地引擎](molecular_car/engine.py)。

保守势能写为：

```math
U=U_{\mathrm{UFF}}+U_{\mathrm{surface}}+U_{\mathrm{drive}}+U_{\mathrm{walls}},
\qquad \mathbf F_i^{\mathrm{cons}}=-\nabla_i U.
```

LAMMPS 采用 `real` 单位制：长度 Å、时间 fs、能量 kcal/mol。表面求力模块内部使用的 eV 在接入引擎时统一换算。

### UFF、分子准备与拓扑

UFF（Universal Force Field，通用力场）用于在较广的元素范围内描述分子的经典机械响应。本项目使用 [RDKit 的 UFF 实现](https://www.rdkit.org/docs/source/rdkit.Chem.rdForceFieldHelpers.html)，保持分子键连接关系不变；比赛期间不发生断键、成键或化学反应。

分子准备包含补氢、参数检查、三维构象处理和几何优化。二维输入可经 ETKDGv3 生成三维构象，再进行 UFF 松弛；三维输入以给定构象为起点处理。放入赛道后，程序关闭驱动与热浴，对“分子内部＋表面＋边界”的联合势能继续松弛。最终检查全部原子受力组成的向量范数是否不超过 **0.0001 kcal/mol/Å**，通过后才进入比赛。实现见 [分子处理](molecular_car/molecule.py) 与 [联合松弛](molecular_car/relaxation.py)。

这一过程寻找可用的局部极小构象，并不保证全局最低能量，也不等同于在目标温度下充分热平衡。当前比赛忽略同位素差异，采用元素的标准质量。

Gasteiger 部分电荷在准备阶段确定，并用于外场响应。本项目的 UFF 内能不额外加入这组电荷的分子内部库仑相互作用；运行中也不进行电荷转移或自洽电荷更新。

### 系综与 Langevin 热浴

赛车采用受驱动的 Langevin 分子动力学，可用下式概括：

```math
m_i\ddot{\mathbf r}_i=-\nabla_i U-\frac{m_i}{\tau}\dot{\mathbf r}_i+\mathbf R_i(t).
```

其中 $`\tau`$ 是阻尼时间，$`\mathbf R_i`$ 是与温度和阻尼相匹配的随机力。阻尼耗散运动能量，随机力补充热扰动，使分子在定向驱动之外仍能平移、转动和变形。这里用 Langevin 热浴近似环境带来的耗散与涨落，没有显式计算金基底的声子。

实现上组合了 `fix nve` 与 `fix langevin`：前者提供 velocity-Verlet 积分，后者施加阻尼和随机力。**使用名为 `nve` 的积分命令，并不意味着实际比赛处于 NVE 系综。** 固定粒子数和盒子、关闭驱动并充分平衡时，Langevin 热浴以正则 NVT 分布为目标；实际比赛受到外场驱动且只观察有限时间，应描述为非平衡过程。参见 LAMMPS 的 [积分说明](https://docs.lammps.org/fix_nve.html) 与 [Langevin 说明](https://docs.lammps.org/fix_langevin.html)。

热浴作用于原子速度，不强行消除每一步随机力的合力，因此质心也能发生随机运动。显示的内部温度扣除了质心平动；150 K 是热浴目标温度，不要求每一帧温度恰好等于 150 K。

### 冻结 Au(111) 与 SAIP

参考表面由六层 Au(111) 构成。层间高度来自预先使用 Au EAM 势松弛的金薄层，面内保留理想 ABC 堆积晶格；详细数据见 [表面参考文件](molecular_car/data/au111_reference.json)。比赛期间金原子固定，既不推进其运动，也不重复计算 Au–Au 内能。

C/H–Au 采用 SAIP（semi-anisotropic interfacial potential，半各向异性界面势）的参数与函数形式作为基础。它包含色散吸引与短程排斥，并通过分子局部法向描述部分方向依赖：同一个原子位于不同晶格位置、或所属片段朝向不同时，表面作用可以不同。因此表面同时提供垂直吸附和横向晶格起伏。

其文献基础是金与石墨类结构界面的势模型：[Ouyang、Hod 与 Guerra，2021](https://doi.org/10.1021/acs.jctc.1c00622)；LAMMPS 提供 [SAIP/metal 的公式与参数说明](https://docs.lammps.org/pair_saip_metal.html)。将它用于玩家设计的任意有机分子，是本项目的建模扩展，不能视为原论文已经验证了所有这些结构。

为支持自由设计的分子，项目对局部法向作了明确适配：

- 用固定的化学键邻接关系选择法向邻居，避免分子折叠时把空间上靠近的无关原子误当成法向邻居。
- 对可定义局部平面的中心，用邻接几何计算法向，随分子运动更新，并把法向变化产生的力传递给相关邻居。
- 对末端、四配位和指定线性环境等不适合这一定义的中心，使用固定表面轴方向；对接近退化的几何加入正则化与求值切换。

表面沿面内方向周期延拓，原子对作用使用 16 Å 平滑截断。**周期化的是表面查询坐标，赛车分子本身保持展开。** 跨越多个晶胞的长分子仍按自身完整坐标计算键、法向、质心和外场，不复制周期镜像赛车。

对 B、N、O、F、Si、P、S、Cl、Br、I，当前没有声称提供同等适用性的 SAIP 参数，而是用元素与 Au 的 UFF 范德华参数作几何混合，得到各向同性 12–6 作用，再在冻结周期晶格上求和与缓存。这些元素可以参与游戏，但对金的化学吸附、成键和电荷转移不在模型内。实现见 [周期表面](molecular_car/periodic_au.py)。

### 赛车怎样被驱动

比赛使用固定在空间中的非均匀场。设 $`x`$ 为赛道前进方向、$`z`$ 为距表面的高度，电势与电场采用：

```math
\phi(x,z)=-(E_0+gx)z,\qquad
\mathbf E=-\nabla\phi=(gz,\,0,\,E_0+gx).
```

外场能量为：

```math
U_{\mathrm{drive}}=\sum_i\left[q_i\phi(\mathbf r_i)-\frac12G\alpha_i|\mathbf E(\mathbf r_i)|^2\right].
```

$`q_i`$ 为固定部分电荷，$`\alpha_i`$ 为按元素指定的有效极化响应系数，$`G=500`$ 为游戏响应增益。设驱动强度为 $`s`$、场增长参数为 $`R`$，实现中 $`E_0=0.5s/\sqrt R`$、$`g=0.0015s\sqrt R`$；默认 $`s=0.6`$、$`R=1`$。这些量采用与势能表达式相容的内部单位，界面上的 0.6 不能直接理解为 0.6 V/nm。

该场在时间上恒定，不依赖一个移动针尖。部分电荷响应和随场强变化的极化能共同影响运动；分子形状、表面接触方式和热扰动进一步决定轨迹。横向没有直接电场分量，但仍有表面力与随机力。公式及单位约定见 [外场实现](molecular_car/fields.py)。

## 代理势 v2 怎样实现

代理势 v2 是**冻结周期金表面势能的数值近似与加速求值方法**。它预先计算表面对不同位置、不同局部方向的作用，再在比赛中快速查询；赛车的坐标、变形与动力学仍逐步计算。它不需要机器学习训练，也没有预先录制分子的比赛轨迹。

### 1. 从同一个冻结表面生成势表

参考计算对截断范围内的 Au 晶格逐项求和。即使金原子不动，直接重复这件事也有成本，尤其是分子的局部法向在不断改变时。

实现把可缓存的标量基底项与方向相关项分开：位置相关的基底项使用周期网格，C 的方向相关部分使用下面的傅里叶与方向插值；常规 H 的固定法向作用可包含在缓存中。其他支持元素保留各自的径向范德华缓存。因此，“代理势 v2”并不表示所有元素都换成了同一张傅里叶表。

### 2. 用傅里叶展开表示面内周期性

对方向相关能量，利用 Au(111) 面内周期性写成有限展开：

```math
U_{\mathrm{dir}}(x,y,z,\mathbf n)\approx
\sum_{\mathbf k\in K}\mu_{\mathbf k}\,\mathrm{Re}
\left[C_{\mathbf k}(z,\mathbf n)e^{i\mathbf k\cdot(x,y)}\right].
```

这里 $`\mathbf n`$ 是局部法向，$`\mathbf k`$ 是表面倒格矢。当前表保留 **12 个独立复系数模式（含零频项）**，共轭模式由倍数 $`\mu_{\mathbf k}`$ 计入。这个展开表示经典势能的空间周期性，与电子的布洛赫波函数不是同一个对象。

模式系数仍依赖原子高度和法向：高度方向采用三次插值，方向参数采用双三次 Hermite 插值，保存系数值与所需导数。当前高度网格间隔为 0.1 Å，共 95 层（包含插值辅助层）；每张方向表使用 13 × 13 个节点。

### 3. 三张方向图覆盖旋转中的分子

如果只用 $`(n_x/n_z,n_y/n_z)`$ 描述法向，片段转到近乎竖直时，分母接近零。v2 使用三张相互重叠的方向图：

```math
(n_x/n_z,n_y/n_z),\quad
(n_y/n_x,n_z/n_x),\quad
(n_z/n_y,n_x/n_y).
```

每张图在自己的有效区域内插值，重叠区域通过归一化平滑权重组合能量。这样可以覆盖非退化单位法向的不同朝向，减少 C60 等曲面分子因法向接近水平而频繁返回昂贵参考求值的情况。

方向图中的两个坐标范围均为 −1.2 至 1.2，节点间隔 0.2。方向图切换参与能量求导；由局部法向产生的链式导数也传回组成该法向的原子。

### 4. 在适用范围边缘平滑返回参考求值

方向代理的高度支持范围为 2.4–11.2 Å，在边缘各设置 0.3 Å 的过渡区。超出范围或法向几何接近退化时，相关方向项返回冻结晶格参考计算，而不是继续外推势表。

过渡发生在标量势能层面。若 $`w`$ 为位置和几何相关的权重：

```math
U=wU_p+(1-w)U_r,
```

则力必须包含权重导数：

```math
\mathbf F=w\mathbf F_p+(1-w)\mathbf F_r-(U_p-U_r)\nabla w.
```

实现保留这一项，以及高度、方向图和局部法向的相关导数。仅混合两组力而遗漏切换权重的导数，会使力与势能不一致。这里的“参考”指项目所定义的冻结 SAIP 模型，并不意味着对真实金表面的严格精确解。

### 5. 1.5 倍晶格起伏怎样施加

晶格起伏系数用于加强横向位置差异，不是把整个表面吸附能直接乘以 1.5。对单个原子的表面能 $`U_i`$，先求同一高度和法向下六个平移位置的平均：

```math
\bar U_i=\frac16\sum_{a=0}^{1}\sum_{b=0}^{2}
U_i(x_i+aL_x/2,\,y_i+bL_y/3,\,z_i,\,\mathbf n_i),
```

再使用：

```math
U_i^{(\lambda)}=U_i+(\lambda-1)h(z_i)(U_i-\bar U_i).
```

$`L_x,L_y`$ 是表面周期，默认 $`\lambda=1.5`$。高度保护函数 $`h`$ 在 2.0 Å 以下为零、2.6 Å 以上为一，中间平滑连接，避免直接放大极近距离的起伏修正。六点平均是这个实现的滤波约定，不等同于精确的整胞连续平均。

平移在傅里叶表示中只改变相位，因此 C/H 加速路径可将六次平移的组合合并到模式求值中，减少重复插值；其他元素的径向缓存路径仍保留相应平移求值。晶格起伏修正及其高度导数同样纳入受力。

### 6. 加速的收益与边界

默认路径用少量模式求和、网格插值和局部法向计算，替代大量重复的 Au 邻居求和。浏览器使用双精度 C++/WASM 求值，势表采用无损压缩下载；本地版本有对应的编译核。

它仍是有限模式与有限网格的近似。代理势减少的是表面求力开销，UFF、分子准备、法向处理和参考回退仍需计算，因此不同分子不会获得相同加速比。相同条件下还应检查能量、力及比赛统计，不能仅凭画面相似认定等价。

## 模型边界与验证

当前模型保留分子内部柔性、表面晶格起伏、局部方向依赖、外场响应和热扰动。尚未包含动态 Au 原子、声子传播、晶体缺陷、反应性成键、电荷转移、自洽金属极化或扫描隧道显微镜的电子激发过程。热浴摩擦也没有显式依赖分子的接触面积。不同结构的成绩应理解为这套游戏模型下的结果。

开发中的数值检查覆盖势能与有限差分受力、局部法向的链式求导、周期平移、插值与切换边界，以及关闭驱动和热浴后的能量漂移；另有时间步比较和完整比赛对照。历史记录见 [开发与 MD 验证说明](DEVELOPMENT_NOTES.md)，当前构建与验证入口见 [WASM 文档](wasm/README.md)。这些检查用于发现实现错误与评估近似，不替代实验验证，也不保证不同平台的长时间随机轨迹逐帧一致。

当前为开源预览版。Chrome、Edge、Firefox 的本地完整流程已验收，公开 HTTPS 站点完成 23 项流程与缓存检查，详见 [发布验收](docs/RELEASE_ACCEPTANCE.md)。手机真机与 Mac/Safari 仍待验证。刷新会丢失未下载的比赛轨迹；工坊工程建议下载备份。

构建浏览器版请从 [构建与发布](RELEASING.md) 开始，固定依赖版本与命令见 [WASM 文档](wasm/README.md)。第三方编辑器修改另有 [Ketcher 构建说明](frontend/editor/ketcher-source/README.md) 和 [JSmol 源码说明](frontend/editor/jsmol-source/README.md)。

本地 Python 版本需要 Windows、兼容的 64 位 CPython 3.11 与 LAMMPS GUI 发行版：

```powershell
.\scripts\setup.ps1 -PythonExe 'C:\path\to\python.exe' -LammpsHome 'C:\path\to\LAMMPS'
.\start-game.ps1
```

打开启动器显示的本地地址。网页玩家不需要执行这些安装步骤。

仓库保留构建所需材料与验证工具；大型轨迹、临时扫描输出、本地虚拟环境和工具链缓存不纳入源码。预编译网页包及第三方对应源码通过 [发行页](https://github.com/chc-cyber/racing-molecule/releases) 提供。
