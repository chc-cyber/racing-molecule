# Racing Molecule

分子赛车核心原型：导入 MOL/SDF 分子，LAMMPS 计算逐原子运动，Three.js 显示赛车与金色跑道。赛车工坊通过独立的分子输入接口接入。

## 浏览器试玩版准备

已打通纯浏览器 WASM 核心试玩：LAMMPS、RDKit UFF 和完整周期 Au 求力在玩家设备的 Web Worker 中运行，网站只发送静态文件。保留现有本地版作为验证基准，GitHub 建议同一仓库提供本地与浏览器两个入口。浏览器默认采用 **150 K、驱动 0.6、代理势 v2、1.5 倍起伏、1 fs**；224 组能量/受力对照和同初态 5 ps 积分对照通过，默认车已在浏览器完成 20 nm 比赛。

构建、预览、版本与正式发布前剩余事项见 [浏览器版说明](wasm/README.md)。整合后的完整网页约 196 MB，试玩 ZIP 约 128 MB，不包含开发者 SDK、Python 环境和上游源码树。浏览器默认使用三方向图代理 v2，首次准备会下载约 30.58 MB 的碳方向表。完整包保留上一代 C/H 表用于开发复现，普通浏览器运行不请求它们。当前尚未公开部署；主页、设置、二维／三维工坊与赛道已在纯浏览器站点中整合。

浏览器傅里叶采用六相位系数合并、Float64 求力与支持域外的完整周期势回退。新增三张方向表覆盖球侧，高度支持扩为2.4–11.2 Å，解决上一代C60大量回退的问题。浏览器默认现为代理势 v2、150 K、驱动 0.6、1.5 倍起伏与 1 fs；阻尼仍为 350 fs，沿程增长仍为 1。采用依据见[默认参数验收](outputs/default-candidate-acceptance/report.html)。本地 Python 入口同步采用这组默认配置；下文历史实验保留当时的参数记录。性能、完整比赛、误差和逐步能量复核见[并行优化报告](outputs/parallel-md-validation/REPORT.md)，上一代结果保存在[首轮傅里叶报告](outputs/wasm-fourier-validation/REPORT.md)。本地 Python 游戏已接入同一 v2 三方向表势能模型，使用 Numba 编译求力与六相位傅里叶合并；Python/NumPy 路径保留为独立数值参考，浏览器使用 C++ 实现。联合松弛仍使用 30 秒预算和全局残余力 ≤ 0.0001 kcal/mol/Å 的检查。9 种代表分子在本机缓存就绪后全部准备成功，总耗时约 0.6–6.4 秒；能量、受力及同初态短轨迹对照见[本地 v2 加速验证](outputs/native-atlas-acceleration/report.json)。

赛事配置在本地 Python 与浏览器 JS 中统一校验，工坊先选规则再准备，并直接交接已就绪的计算进程。当前规则 `race-v1` 使用固定随机种子；只按松弛完成后的质心沿赛道方向净位移满 20 nm 判定完赛。工坊已接入浏览器计算，公开网站部署尚未完成。旧章节和报告中的针尖／脉冲验收属于历史功能，当前接口不再支持。

## 开始试跑

本机环境已经准备好。在项目目录运行：

```powershell
.\start-game.ps1
```

打开 **http://127.0.0.1:8765**，先选赛事和分子，再点击“准备赛车”。标准赛事固定为 **20 nm、代理势 v2、150 K、广域场强度 0.6、1.5 倍起伏、1 fs 比赛步长、350 fs 阻尼**，准备完成后点击“开始试跑”。默认候选分子为 52 原子的四苯基苯，打开页面不会提前启动松弛。

- 默认广域场：沿 20 nm × 20 nm 跑道固定分布，不随赛车移动，也不纠正横向位置。
- 标准／自定义赛事：自定义可在准备前设置温度、驱动强度、表面模型、起伏与沿程增长；步长与阻尼固定。针尖与脉冲已从游戏移除。
- 视角与模型：可跟随分子或查看全跑道；支持球棍模型与空间填充模型切换。
- 播放速度：模型切换按钮下方支持 1×／2×，默认 1× 对应 100 ps / 50 秒，2× 对应 25 秒。计算提前缓冲约 10 ps；算力不足时等待真实坐标，不快进补帧。倍速只改变呈现时钟，成绩始终按原始 MD 位移与时间计算。
- 本地每批 40 ms 固定等待已移除；本地与浏览器共用模拟时间播放、暂停、缓冲与完赛展示流程。首次准备和缓冲等待不计入上述动画时长。
- 金原子跑道：Au(111) 晶格采用哑光暖金色与空间填充球体，远景按分辨率简化晶格细节。
- 比赛操作：开始、暂停、继续与重置；准备后自动收起设置，“本场规则”显示当前已生效的参数。
- 参数修改只影响下次准备；重新准备会清空本场轨迹。比赛中不再热更新电场和温度。标准与自定义比赛通过 `competition.mode` 区分，尚无联网排行榜。
- 切换或导入分子：选择示例，或读取本机 MOL / 单记录 SDF。
- 起跑摆放：默认自动识别贴面姿态与长轴，也可手动旋转或采用文件朝向；有明确车头时可点选车尾、车头原子。应用后重新进行表面松弛。
- 保存轨迹：下载真实坐标、赛事类型、规则版本、完整参数、起跑姿态、随机种子与实际表面模型。

也可以从启动参数加载开发者文件：

```powershell
.\start-game.ps1 -Molecule 'E:\models\my-car.mol'
```

页面只有本机服务，无需账号、Node.js 或联网 CDN。赛车工坊入口为 `/editor/index.html`，核心模拟也可直接使用外部分子文件。首次安装依赖需要网络。按终端中的 Ctrl+C 或运行 `.\stop-game.ps1` 关闭服务。

## 起跑摆放验收（2026-10-13）

本地与浏览器均支持 `rigid-start-pose-v1`，顺序为构象生成/真空 UFF 松弛 → 整体刚性摆放 → 原有零驱动表面联合松弛及受力门禁 → 第 0 步准备就绪。旋转绕质量质心进行，保持键长、连接和手性；比赛中的方向仍自由，没有增加整备电场或方向锁定，也没有改动 0.5 fs、600 K、350 fs 和场强 0.75。

自动模式使用重原子几何主轴判断长轴与贴面参考。长轴方差至少是次轴的 1.3 倍才定义前向；最小方差不超过次轴的 0.25 倍才定义平面。主轴没有天然车头，符号优先选择较接近 +x 的方向，避免仅因原子编号把已朝前的车翻转 180°。近球形分子保留文件朝向；对称平面分子只调整贴面姿态。明确的车尾 → 车头原子对可覆盖自动前向。手动角度相对 UFF 松弛后的文件坐标轴，按 x 侧倾 → y 俯仰 → z 平面旋转应用，不是相对镜头。

姿态只定义联合松弛的起点：松弛可改变方向，界面显示松弛后的原子参考角度；不会在受力验收后再次旋转。修改姿态会清空旧轨迹并重新准备，运行中需先暂停。重置和更换表面保留设置，新导入分子恢复自动模式，回放记录设置与实际摆放元数据。底层 `prepare_molecule` / `Simulation` 不指定 `start_pose` 时沿用文件朝向，保留开发参考算例的旧行为；游戏入口显式传入自动模式。

四种输入（原始/横放/竖直的 52 原子车及连接 C60）× 两种模式 × 两个相同随机种子，共 16 条 5 ps 实际轨迹通过有限坐标、键长和严格准备门禁；最大残余全局力为 8.46e-5 kcal/mol/Å。下表为两个种子的平均值，旋转由固定重原子身份的刚性最佳拟合估计，柔性变形会影响读数。

| 输入 | 前 2 ps 最大倾斜：文件 / 自动（°） | 5 ps 前进：文件 / 自动（nm） |
|---|---:|---:|
| 原始测试车 | 9.04 / 9.04 | 1.288 / 1.288 |
| 横放测试车 | 11.60 / 14.79 | 1.314 / 1.339 |
| 竖直测试车 | 19.63 / 8.17 | 1.356 / 1.253 |
| 连接 C60 | 8.96 / 11.54 | 1.264 / 1.276 |

竖直样例的开场翻转减少，但不是所有车形都改善，也不保证前进更快。该样例准备墙钟时间均值 7.77 → 2.14 秒，仅代表此设备的两次计时，包含缓存/初始化影响，不是通用性能承诺。这是有限时间起步对照，未扫描最快姿态或验证整场排名。

16 组原生/C++ 摆放坐标最大差 3.55e-15 Å；3 组真实 WASM 准备及 1 ps 积分通过。186 项 Python 回归、7 项浏览器传输生命周期检查、既有 224 组能量/受力与 5 ps 成对 NVE 回归通过。结果见 [汇总](outputs/start-pose-validation/summary.json)、[完整原生轨迹报告](outputs/start-pose-validation/final/report.json)与 [WASM 报告](outputs/start-pose-validation/wasm-report.json)。

## 结构差异与温度/驱动扫描（2026-10-13）

本轮使用九种固定导入构象：苯、蔻、炔桥三芳环、折叠正二十烷、四臂测试车、C60，以及极性对照吡啶、苯甲腈、丙酮。保持 20 nm × 20 nm、冻结周期 Au、0.5 fs、350 fs、自动起跑摆放及原有严格松弛门禁；从第 0 步直接比赛，没有额外热整备。所有调用采用游戏原有 100 步批次，首次采样质心 x≥20 nm 为完赛，时间分辨率 0.05 ps。

150/300/600/900 K × 驱动 0.45/0.60/0.75 × 九结构，先完成 108 条 40 ps 单种子筛选轨迹；再对四个条件完成 126 场实际完整比赛，观察上限 400 ps。筛选种子与复测种子独立；150 K / 0.60 每结构五种子，其余每结构三种子。没有用短时速度外推完赛时间，也没有把观察截止时间作为完赛成绩。

|---|---:|---:|---|
| 150 K / 0.60 | 91.78—181.71 | 1.98 | 九结构 × 五种子均有效贴面完赛；推荐作为结构设计对比条件 |

推荐条件中，均值 ± 样本标准差：炔桥 91.78±2.99、蔻 93.52±2.29、苯 96.18±4.33、C60 98.13±1.89、苯甲腈 98.38±6.98、四臂车 99.47±5.97、吡啶 102.07±4.98、丙酮 136.38±12.26、柔性链 181.71±21.91 ps。明显差异主要来自柔性链与丙酮，几种刚性芳香结构仍接近。当前六种 C/H 结构的有效原子响应系数总和/质量为 0.0833–0.1005，刚性芳环更接近；这与它们在强驱动下速度相近相容，但不是完整的摩擦机制分解。

极性对照在真空 UFF 几何上的固定 Gasteiger 模型偶极约为吡啶 1.35 D、苯甲腈 2.20 D、丙酮 2.54 D；这些不是实测或量子化学偶极。N/O–Au 沿用已有未标定的范德华混合近似，完赛差异同时包含质量、构形和表面参数差异，不能单独归因于极性。所测初态的永久电荷直接前向力不超过诱导响应前向力的约 0.016%；电荷仍可通过转向及接触姿态产生间接影响。

234 条轨迹均通过严格准备门禁、有限能量/坐标和键长检查；最大初态残余全局力 9.39e-5 kcal/mol/Å，采样键长/初态比范围 0.801–1.200。126 场全部到达终点，其中 125 场满足本轮贴面有效性判据。离面判据为全原子高于 Au 平面 8 Å 持续至少 5 ps；它是本轮诊断标准，尚未写入游戏计分规则。600 K / 0.60 的吡啶红叉成绩不参与该结构均值和九结构排名，数值正常不等于有效的贴面比赛。准备门禁及比赛动力学未因该样例而修改。

这一结论仅适用于所测参数与固定构象，尚未证明全局最优，也不保证每个刚性分子都能拉开差距。游戏默认配置保持 600 K / 0.75。数据见 [完整汇总](outputs/structure-race-scan/final-report.json)、[均值与标准差 CSV](outputs/structure-race-scan/finish-summary.csv)、[极性诊断](outputs/structure-race-scan/polarity-diagnostics.json)；图表提供 PNG 与 SVG：[完赛对比](outputs/structure-race-scan/figures/02-finish-times.png)、[位移轨迹](outputs/structure-race-scan/figures/03-selected-trajectories.png)、[离面诊断](outputs/structure-race-scan/figures/04-surface-contact-check.png)、[代表结构](outputs/structure-race-scan/figures/00-molecular-lineup.png)。

## 当前模拟模型

所有运动坐标来自 LAMMPS，网页只在相邻真实采样之间插值，不生成赛车运动。当前默认比赛时间步长为 1 fs，每 50 步采样一次（50 fs）；屏幕播放速度与仿真时间分别处理，成绩按仿真步数与实际坐标计算。

名义赛道为 **20 nm × 20 nm**，侧边界为 `y=±100 Å`，纵向软边界仍为 `x=-10/210 Å`。比赛以联合松弛完成后的质心为起点，沿 x 方向净位移达到 **200 Å（20 nm）** 才完赛；横向运动不累计里程，后退扣减进度。起终点标线与进度条使用同一规则，实际终点为 `x_COM(0)+200 Å`。新回放在运行元数据与每帧中保存起点和赛程，截断回放也能恢复正确标线；旧回放保留原来的固定终点规则。几何统一定义在 `molecular_car/track.py`，晶格、电场、边界作用和积分方式没有因这次计分修正改变。下文标为 100 nm / 50 nm 的历史报告保留当时的赛道尺寸，不代表当前赛道。

- **分子内部：RDKit UFF。** RDKit 逐步计算 UFF 能量与笛卡尔梯度，经 LAMMPS 官方 `fix external` 输入；LAMMPS 负责位置、速度积分及 Langevin 热浴。不是把分子替换成任意弹簧网络。UFF 的键、键角、扭转、反转和非键项都保留；Gasteiger 电荷用于外场，不额外宣称 UFF 有分子内库仑项。
- **默认冻结 Au 周期表面：** 六层 Au(111) 的径向/H 标量势缓存，加完整 16 Å 方向项与法向链式力。比赛法向使用固定共价邻接，排除折叠构象中的非键空间近邻；sp、四配位及初态共线环境永久采用表面轴，其他局部平面保守正则化。这是标记为 `bonded-saip-game-v1` 的游戏适配，不宣称原 SAIP 已针对所有车形拟合。原距离选邻居策略保留作参考对照。Au 层高来自随源码发布的 `molecular_car/data/au111_reference.json`，不依赖历史输出目录。
- **连续表面：Morse 吸附与排斥、随高度衰减的三角周期起伏、平滑赛道边界。** 无需模拟金原子。所有保守力与势能一致，包括起伏幅度的高度导数。
- **固定广域场（默认）：** 势 `phi=-(E0+g*x)*z`，场 `E=(g*z,0,E0+g*x)`，表面 `z=0` 的电势为零。`E0=0.5*S`，`g=0.0015*S`，`S` 为 0–1 的作用强度。外势 `q*phi-500*alpha*|E|²/2`，全部力由同一势求导。场只依赖固定空间坐标，不读取赛车质心、针尖位置或时间。场本身的横向力为零；表面起伏和热浴仍可能造成偏移。倍率 **500 是明确的游戏响应参数**，用于在较温和的部分电荷受力下得到可玩的赛程，不是测得的极化率或真实电压。
- **比赛期间固定驱动：** 仅使用广域梯度场；针尖追踪、手动目标和脉冲已移除。底层旧势函数保留供历史数值报告复现，不作为游戏控制入口。
- **默认热浴：150 K、350 fs 阻尼时间。** 使用 `fix nve` 积分加 `fix langevin`；受驱动比赛是开放非平衡过程，不能称为能量守恒 NVE。显示内部温度时扣除质心平移，表面阻尼保留对整体运动的作用。
- **比赛质量：统一元素常规质量。** 同位素标记只在比赛准备副本中移除，准备记录明确提示；原分子文件与工坊中的同位素信息保留。LAMMPS 积分、质心、初始热速度和热浴使用一致的质量。首版不模拟同位素效应。
- **比赛前联合松弛：** 零驱动、无热浴下先 FIRE，再用 Hessian-free truncated Newton，必要时 CG 和牛顿法继续；能量提前停止关闭。完整 3N 保守力的二范数必须 ≤ `1e-4 kcal/mol/Å`，并在最终坐标上重新求力确认，才创建比赛热速度和 Langevin。有限迭代、求力与墙钟预算耗尽会明确拒绝；不会把随机暖机当作几何收敛。
- **首批 12 种元素：** H、B、C、N、O、F、Si、P、S、Cl、Br、I。每个具体分子仍须通过闭壳层/价态、UFF、电荷、异常能量/受力和联合松弛检查。新异元素分子在准备时另做一次全 3N UFF 能量/梯度有限差分检查；比赛仍用解析力。当前 RDKit 版本的三配位 P 明确禁用；高价 I 的实测异常环境和缺参数的六配位 S 也被拒绝，不能把元素名单理解成所有价态均可用。
- **异元素与 Au：** C/H 保留原 SAIP 游戏适配；B/N/O/F/Si/P/S/Cl/Br/I 分别使用独立的非反应 UFF-vdW 混合 12–6 晶格势。UFF 原子类型的 `rmin`/井深来自实际分子，Au vdW 条目为 3.293 Å / 0.039 kcal/mol，几何混合后采用 16 Å 平滑截断。参数文件 `molecular_car/data/hetero_au_v1.json` 明确标为尚未标定的游戏模型；不表示化学吸附、金属配位、镜像电荷或电荷转移。所有 C/H 局部法向仍读取包括异元素在内的完整共价图，其链式力回传到相应原子。

驱动场和极化响应使用游戏有效参数，未经真实 Au/STM 实验标定；没有电子隧穿、金属镜像电荷或反应成键。四苯基苯是四臂结构示例，不是实验 Nanocar。当前逐原子热浴也未实现接触高度相关的摩擦。金球是显示模型；连续模式使用原有效表面，冻结 Au 模式通过周期环境势计算分子与静止金晶格的作用。

广域模式保留 Langevin 的净随机力（没有开启 `zero yes`），因此允许质心随机游走。对默认 382.5 u 赛车，忽略表面起伏的自由质心估算为 `D_y=kB*T*damping/M`：10 K 时约 0.00761 Å²/ps，150 K 时约 0.114 Å²/ps；166 ps 后单轴 RMS 约 0.16 nm / 0.62 nm。这仍小于当前 20 nm 宽赛道。增大阻尼时间会同时减弱阻力并改变噪声，不能将温度或单步随机力大小直接等同于迷路程度。短轨迹实测保存在梯度场验证报告中，不当作收敛的扩散系数测量。

强场基准（强度 0.75）实测 100 nm 用时 167 ps，平均约 600 m/s，属于加速的游戏参数，不是实验 Nanocar 速度。提高温度并不会直接降低驱动速度；想提高热游走在轨迹中的占比，应同时试较弱驱动。首版比赛上限延长为 5 ns，允许弱场跑得更久；极弱场仍可能被表面起伏钉住。真实 MD 降速会增加计算时间，动画播放速度不改变仿真用时。高温测试只检查这个固定拓扑模型的轨迹和键长，不代表真实分子在该温度下不会分解。

连续模型继续保留。小范围显式 Au(111) 参考计算已完成，结果见下文；游戏参数尚未按参考结果重新拟合，也未加入岔路或局部陷阱。

## 金原子视觉与显式表面参考

赛车不向金表面投射阴影。远景表面的承载平面位于顶层球顶附近，通过向下搜索高度材质还原表面。四周始终保留约 6 Å 宽的三维 ABC 金原子边缘，内部使用向边缘内缩的封闭实体兜底；边缘、局部金球和远景表面采用互补裁剪，避免切断或重复覆盖。近景金球围绕相机视线与表面的交点分配，不再跟随相机脚下的位置；旋转到赛道外侧或拉远视角时，顶层与侧面都保持完整。默认 20 nm × 20 nm 跑道的常驻边缘约 2900 个实例、30 万个三角形，内部细节仍按距离简化。这些显示改动不改变 MD 坐标或表面势。

跑道视觉保留约 2.88 Å 最近邻间距和 2.35 Å 层间距的 Au(111) 三层 ABC 晶格，显示半径采用与赛车空间填充模型一致的 Au 范德华半径 **2.1 Å**（RDKit `GetRvdw(79)`）。相邻球体重叠，填住顶层三角孔隙，呈现连续的圆丘表面。近景、远景和背板统一使用哑光暖金色，粗糙度 0.95、金属度 0.05，移除额外的摄影棚反射高光，让赛车更突出。`surface_z=0` 仍表示顶层 Au 原子中心的平均平面，显示球顶约为 2.1 Å；赛车坐标不因视觉模型而平移，标线位于显示球顶上方。近景使用局部实例化球体，实例始终落在固定晶格位置；远景使用同一晶胞的球面法线与高度材质，在原子小于像素时平滑到平均表面，减少摩尔纹。这些金球不参与游戏受力计算。

独立计算采用真实 LAMMPS 的 **Au EAM + 苯/Au SAIP**，读取官方安装附带的 `Au_u3.eam` 与 `CHAu.ILP`，不自行猜测 Au–C/H 的 LJ 参数。Au–Au 用 Foiles EAM，Au–C/H 用 Ouyang 等人的 SAIP；两种势的原始来源和参数文件哈希写入报告。[官方 EAM](https://docs.lammps.org/pair_eam.html)、[官方 SAIP](https://docs.lammps.org/pair_saip_metal.html)

```powershell
.\.venv\Scripts\python.exe -E -B scripts\verify_au_surface.py
```

参考表面约为 **5.77 nm × 6.00 nm，六层、2880 个 Au 原子**；横向周期边界，底两层固定，上四层进行 EAM 最小化。残余最大移动原子力为 `4.35e-7 eV/Å`；随后完成 300 K、5 ps 短热浴检查。吸附扫描使用热浴之前的零温松弛表面，所有 Au 坐标冻结；探针为 UFF 准备的刚性平面苯，关闭外场。吸附能只取 SAIP 界面项，不含 Au 的 EAM 背景和苯内部的恒定 UFF 能。计算采用 `metal` 单位：Å、eV、ps。

该基准说明当前连续势对苯的吸附较弱、参考吸附高度较低，且同高度下更平滑。不能直接将苯的修正倍率用于所有玩家分子，或据此推出摩擦、扩散和赛车速度；这些需要接触动力学验证。短热浴不代表长期稳定性或收敛热统计，小周期表面也不包含 Au(111) 重构、台阶和缺陷。此次 SAIP 参数只用于已验证范围内的苯基准，未扩展到任意元素或扭曲的 52 原子测试车。

## 三种表面的比赛与性能对照

`scripts/verify_surface_racing.py` 在独立进程中比较连续表面、冻结 Au 与可运动 Au，不访问游戏服务。它以 12 原子苯作为已验证的 C/H 界面探针；结果不能直接代表默认 52 原子测试车或任意玩家分子。连续表面保留原来的 Morse 与三角起伏参数。冻结 Au 只计算 Au–分子的 SAIP 界面力，省去恒定的 Au–Au EAM；可运动 Au 另外计算 EAM，底两层固定、上四层运动并连接独立热浴。

所有模型共用 **600 K、0.5 fs 步长、350 fs Langevin 阻尼、固定广域场、20 ps 生产窗口**，强度 0.75 / 0.25 各运行三个种子，共 18 条轨迹。每个配对种子使用完全相同的分子初始速度数组，但不假定后续 Langevin 随机力逐步相同。分子先在各自表面进行零场、仅垂直方向的松弛；可运动 Au 另外预热 2 ps，此时间不计入比赛时间。横向周期边界允许跨越小表面，坐标与驱动均使用未折回的真实位置；连续模型的赛道边界在对照中关闭，避免混入墙壁效应。

.\.venv\Scripts\python.exe -E -B scripts\plot_surface_racing.py

## 显式 Au 优化与冻结周期势

游戏的“自定义赛事 → 表面模型”提供连续表面、冻结 Au 周期势和代理势 v2。点击准备后由新模拟进程重新准备赛车、清空旧轨迹；驱动固定为广域梯度场。冻结 Au 使用独立的晶格起伏倍率，连续表面使用原有起伏参数。金晶格的近景原子、远景材质使用同一真实间距、ABC 相位及顶层高度。

显式参考支持安全缩胞：六层 Au 从 20×12 的 2880 原子减至 14×8 的 1344 原子，实际约 4.039×3.998 nm，保留原松弛层高度和 16 Å taper。每次按**完整、未折回的分子跨度**检查晶胞；过小则自动扩胞或严格拒绝，不把赛车拆成多个周期片段。保守下限采用 `max[2*(cutoff+skin), span+2*(normal_cutoff+skin)]`。前一项是本基准的安全策略，LAMMPS 本身允许 cutoff 超过半个晶胞；法向邻居不混入赛车副本才是单分子模型的重要约束。

本机 SAIP/OPT 的能量与普通 SAIP 一致，但逐原子力未通过全笛卡尔有限差分：平面探针最大差约 `8.62e-5 eV/Å`，局部弯曲探针约 `3.54e-3 eV/Å`。因此默认使用普通 SAIP，实验 OPT 必须显式选择 `allow_unapproved_opt=True`。单独 EAM/OPT 与普通 SAIP 组合通过验力，但此次短测只快约 1.7%。冻结 Au 的安全缩胞约快 **1.24 倍**；可运动 Au 约快 **1.55 倍**。后者也改变周期声子谱，不能把性能测试当成比赛物理已经等价。

快速模式中，LAMMPS 只积分完整赛车，没有显式 Au 或赛车周期副本。六层晶格在环境势里重复；只有表面查询坐标周期化，分子的键、局部法向、质心与驱动使用完整真实坐标。SAIP 的径向部分及固定法向的 H 部分缓存为周期三维标量势，碳的方向项仍完整求和到 **16 Å**，并保留法向导数传回相邻原子的链式力。非平凡 H 法向也保留方向校正。缓存插值的力取自同一个势的解析导数。高度 2–12 Å 内使用 `32×60×407` 网格，两端 0.3 Å 平滑混合到精确计算，并计入混合权重的导数；域外不钳制坐标。

Numba 将同一求力计算编译为单线程 CPU 核，保留 NumPy 实现作为可选择的对照与缺少编译库时的后备。首次势表构建实测约 12.8 秒；表和编译函数按参数、几何、版本缓存，后续重新准备直接复用。首次构建、加载及编译的时间与 MD 传播时间分别记录，不计作运动加速。全部计算仍保留 UFF、LAMMPS 0.5 fs 积分与 Langevin 热浴，不预录赛车运动。

同机单线程、12 原子苯、600 K、强度 0.75 的完整 MD 短测速如下。各方法预热 1000 步，计时三个连续的 2000 步区间，表中为首个配对种子的区间中位数；不包含势表准备、编译、采样和绘制。

|---|---:|---:|

## 静态 Au 傅里叶代理

“环境设置 → 表面模型”现在另有 **冻结 Au 傅里叶代理**（`fourier-au`）。当前启动默认采用代理势 v2，完整周期缓存与连续表面保留为可选模式。以下记录 v1 的实现与验收；v2 说明见本页开头。三种表面都使用真实的 LAMMPS 积分、UFF 分子内力和现有两种驱动；表面切换重新准备比赛。界面与回放记录实际选用的势、缓存参数和每帧的代理／混合／参考方向项计数。金原子视觉仍与同一 Au(111) 晶格匹配，球棍与空间填充只改变显示。

此模式是在经典周期势上作空间傅里叶展开，**不是电子 Bloch 波函数**。沿用原周期缓存的径向项与固定法向 H 项，把剩余完整 SAIP 方向响应压缩为 **12 个独立复谐波（含直流项）**。局部法向使用 `a=nx/nz, b=ny/nz` 的有限坐标图，缓存值与方向的一阶／混合导数，以双三次 Hermite 插值；高度用同一标量势的三次插值。位置导数、法向导数以及对完整分子相邻原子的链式力均保留，不能把方向作用简化成法向平方。

v1 加速支持域为高度 **2.8–8 Å**、`|a|, |b| ≤ 2`，高度边缘 0.3 Å、方向边缘 0.4 平滑混合。域外恢复完整 16 Å 方向项求和；全部混合权重的导数计入力。原径向缓存仍按其独立的高度支持域与精确径向计算衔接。因此赛车可以倾斜和翻转，域外计算可能更慢。游戏近退化平面另以法向平方模 0.999–0.9999 的 C2 权重回退完整求和，并保留权重与法向链式导数。原参考策略与游戏策略均保留；角度傅里叶表只用于 C/H，异元素使用同一独立径向晶格势，不增加庞大的角度表。分子、键、法向和驱动不折回 Au 原胞，只有周期背景查询使用晶格相位。

本机首次傅里叶表生成约 **90.85 秒**，数组为 `2×111×21×21×4×12` 复系数；加上写盘等初始化约 92.73 秒。缓存使用参数／几何／算法哈希、形状和类型验证与原子写入，后续直接加载；建表与编译不计入 MD 测速。编译求力采用同一单线程 Numba 环境，保留 NumPy 对照。

验收包括原来的 36 个原生 LAMMPS 对照构型，以及另外 32 个随机朝向、4 个非平凡 H 法向构型，共 **72 个**。另做 11 个完整笛卡尔有限差分检查，包含高度与方向混合区域、近水平法向和 H 邻居链式力。原对照集合覆盖 52 原子车，以及跨度 90.254 Å 的 212 原子完整长分子和多胞平移。原集合最大吸附能差约 `1.51e-5 eV`、最大原子分量力差约 `5.78e-4 eV/Å`；新增完整求导检查最大差约 `5.27e-7 eV/Å`。支持域外的方向项回退也参加验收；这些结果是已采样构型的误差，不是所有玩家分子的统一误差界。

完整 MD 对照使用相同的大模拟盒、分子回调、12 原子苯、600 K、强度 0.75、0.5 fs 步长与 350 fs Langevin 阻尼。每种模型三个种子，各预热 1000 步并计时三个 2000 步区间；下表为三个种子区间中位数的中位数，准备、采样与绘制不计入。

| 表面模型 | 完整 MD 单步推进 / μs |
|---|---:|
| 原连续模型 | 129.37 |

## 分子文件约定

支持带键信息的 MOL V2000/V3000 与单记录 SDF。二维结构自动生成三维并补氢；已有三维结构保留朝向，进行 UFF 松弛，然后在跑道上最小化。准备完成后先暂停，等待玩家开始。

## 晶格起伏与电场沿程增长（2026-10-14）

新增两个独立控制：`settings.lattice_scale` 是冻结 Au 的主要晶格起伏倍率，`drive.growth` 是固定广域场的沿程增长倍率。现行默认分别为 **1.5** 和 **1**；默认 150 K / 驱动 0.6 / 350 fs Langevin / 1 fs 比赛时间步。完整周期势与傅里叶代理都支持起伏控制；浏览器现已支持这两种模式。连续表面沿用原 `corrugation` 控制。

**论文参数与游戏倍率：** C/H 继续读取原 `CHAu.ILP` 参数，保持 16 Å 截断、原平滑截断与单位换算。原 SAIP 同时拟合吸附与滑动势能面；新增倍率是独立的游戏调节，参考值为 1。它不采用参数文件中对整个相互作用能量缩放的 `S` 代替起伏控制。[SAIP 论文](https://doi.org/10.1021/acs.jctc.1c00622)、[LAMMPS 参数说明](https://docs.lammps.org/pair_saip_metal.html)。N 等其他元素继续使用已明确标记为暂定游戏近似的 UFF-vdW/Au 势。

起伏控制采用 `six-phase-atomic-crystal-contrast-v3`：完整分子沿 Au 矩形晶胞的 `2 × 3` 相位平移，只改变表面查询坐标。对每个相互作用中心求相位平均 `Ū_i`，使用 `U_i + (λ−1) w(z_i)(U_i−Ū_i)`。局部保护 `w` 在 2–2.6 Å 之间按五次多项式平滑变化，在更近处采用原短程势，在普通接触高度采用完整倍率。所有位置导数、保护函数导数和按相互作用中心加权后的法向链式力均保留。某个氢的保护不会关闭其他原子的晶格调制。

这保持固定构型与高度下的连续晶胞平均吸附势。实际优化后的吸附高度、构型与局部势阱深度可以改变，需通过比赛轨迹验收。有限相位平均保留高阶晶格波纹；倍率 0 在保护区之外选择这个更平滑的参照，近表面仍混合原势。倍率 1 严格走原求力路径。非 1 倍率当前计算六个相位，属于更耗算力的验证实现。界面提供 0–3 倍；内部研究接口允许 0–12 倍，极端值只做过部分静态验证。

广域场保持静态势 `φ = −(E0+g x)z`，对增长倍率 `R` 使用 `E0 = 0.5 s / √R`、`g = 0.0015 s √R`。这样保留 x=0 处的诱导推力，沿程相对增长变为原来的 R 倍。20 nm 内原诱导推力增长约 60%；R=0.25 时约 15%。竖直诱导项与电荷取向作用也随之改变，均由同一势能求导并验收。R 支持 0.1–2；当前游戏只提供固定广域场。

新增滑块位于“环境设置”。在界面调整两项会清空本轮轨迹、重新准备并从第 0 步开始；直接调用控制 API 仍允许热更新，客户端需自行重置才能开始可比较的新比赛。比赛扫描中每轮参数固定。时间步、逐原子 Langevin 及 UFF 分子力场未修改。

开发验收使用 `scripts/data/crystal-race-inputs/` 中七个固定中性三维分子：苯、蔻、炔连接结构、四苯基苯、C60、吡啶、苯甲腈。排除丙酮和正二十烷。完整比较统一执行真实 LAMMPS/RDKit C++ WASM，用 150 K / 驱动 0.60，比较起伏/增长 `(1,1)、(1,0.25)、(2,1)、(2,0.25)、(3,1)`，每种分子每组 3 个独立 Langevin 种子，原浏览器初始化速度种子 17329。每 100 步采样，每 0.5 ps 保存完整坐标；20 nm 为 COM 首次跨过 x=200 Å，400 ps 未完成记右删失，不推算用时。全车连续离面超过 8 Å 达 5 ps 的轨迹不作为有效表面成绩。

## 浏览器非单位起伏的等价求力优化，2026-10-14

浏览器 C++ 求力已合并六相位的法向计算与链式求导，预平均对齐的周期势表，并使用保守 Au 候选位点表。碳原子的常见接触路径单独编译，减少循环分支。仍使用 Float64、原 16 Å 截断、原 UFF、0.5 fs 步长和 Langevin 参数；1倍起伏保留原计算路径。本地 Python/Numba 实现没有改动，继续作为参考。

本机 i9-13900HX、Node 24 的实际 WASM 串行交替计时中，七种分子在1.5/2倍起伏下的总 MD 耗时降低约13%–19%。按3次2 ps样本的中位数折算100 ps：苯约63→53秒，吡啶约51→44秒，四苯基苯约291→248秒，C60约454→366秒（此处列1.5倍）。这是纯计算成本的短段外推，不包含下载、准备、渲染，也不是完整比赛计时。

**该轮尚未达到普遍半分钟等待的目标。** 当时Worker仍保留每100步约40 ms的播放节奏，100 ps名义上还有约80秒的播放下限；这三项优化没有引入近似代理。后续浏览器傅里叶轮次已取消该节流，并合并代理的六相位系数，最新结果见本文开头及[傅里叶验收报告](outputs/wasm-fourier-validation/REPORT.md)。

验证记录、完整比赛对照及性能图见[本轮报告](outputs/surface-kernel-optimization/REPORT.md)。旧147场研究记录不覆盖重写；它们对应的优化前源码与WASM归档在`outputs/surface-kernel-optimization/reference/`，原研究的源码哈希门槛不会被放宽。

## 代码边界

- `molecular_car/molecule.py`：分子文件与统一 UFF 准备。
- `molecular_car/fields.py`：外势参考实现（包含仅供历史复现的旧针尖势）。
- `molecular_car/fields_kernel.py`、`external_fields.py`：同一外场的融合编译核、复用数组与 NumPy 对照路径。
- `molecular_car/explicit_au.py`：安全缩胞与原生 SAIP 参考计算。
- `molecular_car/periodic_au.py`、`periodic_au_kernel.py`：冻结 Au 的周期势、解析求力与 CPU 编译加速。
- `molecular_car/fourier_au.py`、`fourier_au_kernel.py`：静态 Au 方向响应的傅里叶／Hermite 代理和保守回退。
- `molecular_car/engine.py`：LAMMPS 受力、积分、控制与轨迹。
- `molecular_car/server.py`：本地网页与隔离的模拟进程。
- `frontend/`：Three.js 场景、视觉样式与控制界面。
- `THIRD_PARTY.md`：第三方组件来源与许可说明。
