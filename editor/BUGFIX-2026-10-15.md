# 网页工坊构象与氮价态修复

## 原因与改动

- **[6]螺烯**：标准 ETKDG 和随机坐标重试均可能无法满足平面 sp2 先验。现在先进行两次短尝试，再允许弯曲芳香构象，保留距离、扭转和立体检查。采用 [RDKit 上游说明](https://github.com/rdkit/rdkit/discussions/5841)中的回退思路。自动构建不调用 UFF，生成的是可继续编辑的初始构象；局部几何可由玩家显式优化。普通分子仍优先使用完整 ETKDG。
- **中性亚胺氮**：Ketcher 3.18.0 的 N/P 共用价态分支会把键级之和为 4 的中性氮按五价处理，并显示一个隐式 H。源码扩展现将中性 N 限为三价，调用原生红色错误标记。正电荷亚胺鎓及磷规则保留；无效草稿仍可编辑、保存和撤销，三维生成返回价态错误。
- **C60**：网页版先前遗漏了本地工坊的球壳种子和局部构造流程，整个笼状分子被重新嵌入。新增 `wasm/src/editor_construction.hpp`，按稳定 ID 使用模板球壳，只构造新增片段，完成后补氢。新增单点连接片段采用局部构象与刚性对齐；原有坐标保持原值。多固定连接点仍需手动调整或显式重建。

## 构建与验收

```powershell
node frontend/editor/ketcher-source/build-native-c60.cjs
.venv/Scripts/python.exe -X utf8 -E -B wasm/tools/build.py --link-only
node --test tests/browser-workshop.test.mjs tests/browser-workshop-regressions.test.mjs
.venv/Scripts/python.exe -m unittest tests.test_editor_curved_construction tests.test_editor_initial_construction
.venv/Scripts/python.exe wasm/tools/package_web.py
.venv/Scripts/python.exe wasm/tools/verify_package.py
node scripts/verify_workshop_regressions.cjs
```

浏览器验收使用独立静态服务和 `/racing-molecule/` 子路径，执行真实 Worker/WASM、Ketcher 与 JSmol，不调用比赛 API。覆盖 [6]螺烯、原生 C60 模板、氮上拖出新键后的红色提示、加正电荷修复、二维／三维切换、完整工程撤销和重做。数值回归另外覆盖 11 环螺旋结构、C60–CH3、C60–苯环、原有坐标与 ID、MOL/SDF 和手性信息。

验收输出：`outputs/workshop-bugfix/`。静态发行输出：`wasm/dist/` 与 `outputs/wasm-preparation/racing-molecule-web-preview.zip`。本次生成本地发行材料，不自动推送 GitHub 或发布 Pages。

Ketcher 扩展版本为 `3.18.0+molecular-car.c60.4`，源码补丁、版本清单、Apache-2.0 与依赖版权声明随构建保存。未修改比赛引擎、UFF 参数或比赛准备流程。
