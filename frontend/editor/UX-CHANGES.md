# 分子赛车工坊：交互更新

## 2026-10-12：成熟二维绘图接入

主二维画布已替换为本地 Ketcher 3.18.0。原生键工具、环模板、选择 / 删除、原子属性与周期表直接可用；无需再维护自写 SVG 的基础绘图交互。顶部保留工坊文件、统一历史、生成 / 整理、赛车片段和送入赛道功能，二维中隐藏重复的外层元素与键型工具。

同期实现 live Pool ↔ UUID 显式绑定、无反馈循环的事件桥接、统一撤销与快捷键、导入失败恢复，以及 3D 文件的索引式二维立体描画。C60 连接与价态检查依然由共享模型执行。坐标 / 稳定身份保护优先于直接调用会重新编号的原生整理操作，相关操作使用工坊按钮。

JSmol ModelKit 已在本地完整 runtime 实际验证，见 [实测记录](research/jsmol-live.md)。本轮主三维仍使用原有真实构造工具；发现的自动改键长 / 氢与原生历史 ID 限制有可复现证据，不宣称完成 JSmol 主页面替换。当前操作和验收入口见 [README](README.md) 与 [VALIDATION](VALIDATION.md)。

下方记录 2026-10-11 自写绘图阶段的交互与研究历史，相关二维快捷键和选择规则不再代表 Ketcher 主画布。

更新日期：2026-10-11。本次重点是减少常驻文字，并把分子构造操作移回画布。界面用图标、悬停提示和情境浮层表达常用操作，保留保存、导出、立体化学和数据保护能力。

## 页面与操作

| 区域 | 新操作 |
|---|---|
| 顶部 | 工程名、文件菜单、保存/导出、统一撤销重做；“送入赛道”保留文字 |
| 工具条 | 2D/3D、常用元素与完整周期表、键型、显式三维生成/几何整理/二维排版、试跑检查、帮助 |
| 左侧 | 选择、框选/套索切换、原子、键、片段、移动、旋转、几何、删除 |
| 画布 | 占用主要空间；选择原子/键后显示相关操作浮条，高级属性按需展开 |
| 底部 | 当前操作短提示、原子/键数量、结果或错误摘要；长原因在详情弹窗 |

图标有可访问名称、悬停提示和状态反馈；键级直接用 — / = / ≡，元素仍用标准化学符号。必要的操作影响和错误原因不会只靠图标或颜色表达。

## 二维绘制

键工具从空白或已有原子拖出新键，拖到空白延长链，吸附到已有原子可连接或闭环。预览显示新键和目标，默认二维长度 1.5、方向按 30° 吸附；Alt 自由绘制。二维长度约束只影响排版。

选择工具可单选、框选、套索、Shift 增减选、拖动已选对象；双击选择连通分子。二维骨架默认隐藏多余碳标签与编号，悬停、选择和编号开关辅助定位。键级、电荷、楔线和删除通过情境工具条快速修改；同位素、CW/CCW 与 E/Z 仍可在属性面板操作。

元素热键作用于悬停原子，1/2/3 作用于悬停键；没有画布热点时可切换工具。输入框、搜索和弹窗保留自己的键盘输入，避免字母工具键抢走元素搜索。

## 周期表与元素替换

顶部常用元素与周期表共同控制原子工具。周期表有全部 118 元素，采用 18 列与独立镧系/锕系行；可按符号、中文名或原子序数搜索，方向键移动，Enter 选择，Esc 取消。

普通入口选元素后激活添加/替换工具：点空白添加，点已有原子替换。选择单个原子时，周期表底部提供明确的替换当前选择动作；所选原子的情境元素按钮直接以替换模式打开。未选原子、多选或原选择已失效时不能用单原子替换动作。

元素替换仍由共享模型处理，保留该原子的稳定 ID，加入统一撤销记录并处理受影响的立体标记。所有元素都能用于保存设计，试跑支持范围通过独立检查返回。

## 三维编辑

右键旋转视角、中键平移视角、滚轮缩放持续可用；左键承担构造与手柄操作。移动和旋转工具采用 Three.js TransformControls 轴/平面与旋转环，改变真实三维坐标；“片段整体操作”默认保护 C60 等片段内部形状。

几何工具按顺序选 2/3/4 个连续原子，分别调键长、键角、二面角。浮层显示当前值，数字框与滑块联动；选择顺序、固定侧与移动侧直接标在画布。可交换固定/移动侧；“应用”才写入一次历史，“取消”丢弃预览。修改预览后，保存、导出和送入赛道都会要求先应用或取消，确保这些操作处理的是已确认构象。

## 片段

选择苯环、炔基、C60 或自定义片段后先显示半透明预览和活动连接位点。点空白独立放置，点已有原子连接；预览无效时显示原因。连接按真实原子、键与声明端口检查价态，不因视觉重叠自动改拓扑。

放置保持当前相机；首次在空工程中添加时才适配视图。自定义片段保存弹窗可命名并勾选多个允许连接的原子，不选端口时只能独立放置。C60 仍是 60 个原子和 90 条键，初始饱和位点不允许直接超价连接。

## 数据与赛道边界

二维排版和三维构象仍分别保存，同一个分子拓扑与稳定原子 ID 支持视图联动。普通拖动、切换视图、保存不会按距离重判化学键，也不会自动重生成三维。原生工程保留坐标、拓扑、片段与立体字段；MOL/SDF 文件继续使用既有校验和导出约定。

几何预览可取消，拖动不会逐帧优化；异步生成/整理结果绑定版本，旧结果不能覆盖新编辑。统一撤销恢复拓扑、两套坐标与片段信息。

只有明确点击“送入赛道”才调用 `/api/load`，并按本次 `generation` 等待准备到 `paused` 或显示 `error`。界面预览与检查不触发比赛加载。后端补氢、松弛和平移语义保持原有约定，因此不能承诺赛道构象与手工编辑器坐标完全相同。

## 已知限制

- 片段初始位置/方向对齐不包含碰撞消除或全局构象搜索；可继续手工调整或显式整理几何。
- 环内键无法通过切除一条键确定移动侧时拒绝自动分侧几何调整；直接坐标移动可能产生不合理构象。
- 价态提示和当前试跑支持范围分开；超重元素可设计保存，不代表有当前 UFF/Gasteiger/LAMMPS 参数。
- 跨手性中心的拓扑修改仍需要重新指定相关立体标记。无自动反应立体推理、轴手性或增强立体组。
- 多记录 SDF 仍明确拒绝，需要先拆成单记录；SDF 属性表、S-groups、查询结构不保留。
- 浏览器暂存和撤销历史不提供跨浏览器协作，撤销栈不跨刷新。罕见元素汉字的显示取决于系统字体，但符号、序数与部件搜索别名可继续使用。
