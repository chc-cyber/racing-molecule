# 赛道界面文案

赛道与分子工坊使用同一套语言规则：按钮直接写动作，正常反馈报告结果，失败提示保留原因和处理办法。标题采用页面名称，不使用刻意拆句的标语。

- 状态用“准备分子…”“准备就绪”“比赛中”“已暂停”“已完赛”；达到时限时显示具体结束原因。
- 显示模型通过按钮选择，不重复解释球棍和空间填充的绘制方式。
- 起跑摆放保留模式、旋转顺序和实际摆放结果。应用姿态、重置、更换模型及修改起伏倍率/沿程增长会清空轨迹并重新准备，这些影响在对应操作处说明。
- 表面选择只说明连续表面、周期金晶格与加速近似的区别。元素准入、赋参、冻结晶格、代理表版本及求力细节见根目录 README 和 wasm/README.md。
- 准备失败原样显示服务返回的原因。连接失败补充启动服务或刷新网页的处理方式，不把失败显示为成功。
- 轨迹按钮发起浏览器下载，因此反馈为“已发起轨迹下载”，不声称文件已经保存到磁盘。当前比赛和上一场比赛入口保留。
- 准备失败后不显示可用的开始按钮文案。未接入的浏览器工坊和界面原型功能，在对应入口处明确说明。

原有 DOM ID、数值单位、参数范围、接口和控制绑定保留。隐藏的 `scene-description` 与 `representation-note` 是兼容节点，不再写入重复说明。

浏览器赛道通过 `wasm/tools/package_web.py` 从原生前端生成；网页原型通过 `web-ui/refresh-preview.mjs` 与 `web-ui/build-offline.mjs` 同步。不要只编辑生成目录。

标准赛事只显示赛事名称与必要的距离，不列出固定温度、驱动、步长或晶格参数。赛事开始后到结束或重置前锁定赛事选择，暂停期间继续锁定。参数的完整记录仍保留在回放和研发文档中。

比赛按钮采用左上、右下两个切角。`race-theme.css` 保存三套候选配色；已选 A 的暖白配色，朱红降低饱和度为 #C44B3A，按钮采用纯色色面与双切角轮廓，不使用棱线、渐变或纹路，连接状态圆点使用绿色。电蓝和荧绿保留为历史对照，首页品牌构图保持不变。
